項目約定
清單類型personal（生日）· registry（孕婦／婚禮）· relief（救災，Phase 2）
品項模式quantity（數量認領，送禮者自行購買）· crowdfund（點數眾籌，Phase 2）
點數1 點 = NT$1，只能投入心願品項，任何人都無法提領給受捐者；達標後由平台自動下單（目錄商品）或人工代購
點數來源儲值（可退現金）· 禮物卡兌換（不可退現金）· 星星兌換的贊助點數（90 天到期）；認捐扣點順序：贊助 → 禮物卡 → 儲值
認領狀態reserved → purchased → delivered；cancelled／expired
認捐狀態pledged → captured（達標下單）；released（退回錢包）／reallocated（轉投其他品項）
品項募集狀態open → funded → fulfilled；expired（截止未達標）
分期P0 MVP（personal + registry 數量認領）· P1（連結預覽、通知、換裝置找回）· P2-A 錢包＋眾籌＋自動儲值 · P2-B 禮物卡＋回饋星星 · P2-C 企業禮券 · P2-D 救災
APIhttps://api.wishsync.tw/api/v1，錯誤格式 RFC 9457 problem+json，建立類 POST 必須帶 Idempotency-Key
